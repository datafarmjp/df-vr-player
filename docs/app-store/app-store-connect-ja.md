## アプリ名

DF VR Player

## サブタイトル案

VR180 / VR360 ローカル動画プレイヤー

## プロモーションテキスト案

Mac 上の VR180 / VR360 動画を、履歴、ブックマーク、プレイリスト、別名管理とあわせて快適に再生できます。

## 説明文案

DF VR Player は、Mac に保存した VR180 / VR360 動画を再生するためのローカル動画プレイヤーです。

VR180 / VR360 / 2D などの投影モードを切り替えながら、手元の動画を整理して再生できます。履歴、ブックマーク、プレイリスト、別名管理に対応しているため、撮影データや検証用動画を繰り返し確認する用途にも向いています。

主な機能:

- VR180 / VR360 / 2D 動画の再生
- LR / TB / SBS などの表示モード切り替え
- 再生履歴
- ブックマーク
- プレイリスト
- CSV によるプレイリスト読み込み、保存
- ファイル別名管理
- 日本語 / 英語 UI

DF VR Player はローカルファイルを再生するアプリです。動画ファイルの内容は外部へ送信されません。

## キーワード案

VR180,VR360,video,player,local,stereo,360,180,playlist,bookmark

## スクリーンショット撮影リスト

- メイン再生画面: 動画を開いた状態
- 投影モード切り替え: VR180 / VR360 / 2D の切り替えが見える状態
- 履歴パネル: 再生履歴が表示された状態
- ブックマークパネル: ブックマークが表示された状態
- プレイリストパネル: 下部ツールバーが見える状態
- 設定画面: 言語切り替えと About 情報が見える状態
