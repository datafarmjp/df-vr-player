# App Review メモ案

## アプリ概要

DF VR Player は、利用者が Mac 上で選択したローカル動画ファイルを再生する VR180 / VR360 対応プレイヤーです。アカウント登録、ログイン、外部サービス連携は不要です。

## テスト手順

1. アプリを起動します。
2. 左下のファイルボタンから動画ファイルを選択します。
3. 上部の投影モードを切り替えて表示を確認します。
4. 履歴、ブックマーク、プレイリスト、設定画面を確認します。

## Mac App Store 版の挙動

- 外部アップデート確認は表示しません。
- GitHub Release や外部ダウンロード導線は表示しません。
- 開発支援、決済、寄付リンクは表示しません。
- ファイルは利用者がファイル選択ダイアログで選んだものを扱います。
- `/Volumes` の自動探索によるファイル復旧は行いません。
- アプリ内課金、サブスクリプション、外部購入導線はありません。

## プライバシー

動画ファイルの内容、再生履歴、ブックマーク、プレイリスト、別名情報は外部サーバーへ送信されません。アプリはローカル再生を目的としています。

## 審査補足

動画サンプルが必要な場合は、一般的な mp4 / mov 動画で動作確認できます。VR180 / VR360 動画がなくても、2D モードでファイル選択と再生の基本動作を確認できます。
