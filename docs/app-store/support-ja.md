# DF VR Player サポートページ文面案

DF VR Player は、Mac で VR180 / VR360 などのローカル動画を再生するためのアプリです。

## サポート対象

- アプリの起動、再生、ファイル選択に関する問題
- 履歴、ブックマーク、プレイリスト、別名管理に関する問題
- Mac App Store 版の購入後の利用に関する問題
- 不具合報告、改善要望

## お問い合わせ時にあると助かる情報

- macOS のバージョン
- DF VR Player のバージョン
- 問題が起きた操作
- 再現手順
- 表示されたエラーメッセージ

## 注意

動画ファイルそのものの提供は不要です。必要な場合でも、ファイル名、形式、長さ、コーデックなど、個人情報や動画内容を含まない情報で確認します。

## App Store Connect 登録メモ

サポート URL は公開ページが必要です。初回申請前に、上記内容を自社サイトまたはサポートページへ掲載してください。
