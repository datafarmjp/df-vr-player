# DFVRプレイヤー

DFVRプレイヤーは、MacでVR180/VR360動画を見るためのデスクトップアプリです。ローカルディスク、外付けドライブ、Finderから見えるNAS上の動画ファイルを開いて再生できます。

## 主な機能

- `.mp4`, `.mov`, `.m4v`, `.webm` の動画を開けます。
- VR180/VR360、2D、Side-by-Side、Top-Bottomの表示に対応します。
- ファイル名や動画サイズから、投影モードを自動推測できます。
- マウスドラッグで視点を動かし、ホイールやトラックパッドでズームできます。
- プレイリストを使って、複数の動画を続けて視聴できます。
- 最近開いた動画の履歴から、見たい動画を探し直せます。

## こんな場面に向いています

VR180やVR360の動画をMacで確認したいとき、撮影素材を整理しながら見返したいとき、ローカルやNAS上の動画をすばやく再生したいときに向いています。

## 利用について

Mac向けのアプリとして配布しています。互換性を重視する場合は、H.264のMP4を推奨します。HEVC/H.265の再生可否は、macOSおよびアプリ内ブラウザエンジンの対応状況に依存します。
